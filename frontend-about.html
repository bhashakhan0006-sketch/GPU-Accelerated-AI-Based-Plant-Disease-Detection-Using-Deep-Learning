About the Project

AI Powered Plant Disease Detection Using Deep Learning

Project Objective

The objective of this project is to build an Artificial Intelligence system capable of detecting diseases in plant leaves using Deep Learning. The system analyzes uploaded leaf images and predicts whether the plant is healthy or affected by a disease. NVIDIA GPU acceleration enables faster model training and prediction, making disease detection more efficient.

Problem Statement

Plant diseases reduce crop quality and agricultural productivity. Manual disease identification requires expert knowledge and consumes valuable time. This project provides an automated solution using Deep Learning, allowing farmers and agricultural professionals to identify plant diseases quickly and accurately.

Main Features

Image Upload

Users can upload a plant leaf image directly from the website.

AI Prediction

Deep Learning CNN model predicts the disease with high accuracy.

Fast Processing

GPU acceleration reduces prediction time significantly.

Technologies Used

HTML5 CSS3 JavaScript Python Flask TensorFlow Keras OpenCV CUDA NVIDIA GPU

Project Workflow

  1. Upload Plant Leaf Image
  2. Image Preprocessing
  3. Deep Learning Model Prediction
  4. Disease Classification
  5. Display Disease Name & Confidence
