The GPU-Accelerated AI-Based Plant Disease Detection Using Deep Learning project is an AI-powered web application designed to identify plant diseases from leaf images using deep learning techniques. The system utilizes MobileNetV2 Transfer Learning with TensorFlow/Keras and leverages NVIDIA GPU acceleration to improve training and inference performance.

The application provides a simple and user-friendly interface where users can upload a plant leaf image and receive an instant prediction that includes the disease name, confidence score, and plant health status. The backend is developed using Flask, while the frontend is built with HTML, CSS, and JavaScript, creating a complete end-to-end solution for intelligent plant disease detection.

This project demonstrates the practical application of Artificial Intelligence, Computer Vision, Deep Learning, and GPU Computing in agriculture, helping farmers, researchers, and students detect plant diseases quickly and accurately.

🎯 Project Objective

The primary objective of this project is to develop an AI-based system capable of automatically detecting plant diseases from leaf images with high accuracy. By combining deep learning and GPU acceleration, the application enables faster model training and real-time disease prediction through an easy-to-use web interface. The project aims to support smart agriculture by assisting users in identifying plant diseases at an early stage, thereby contributing to improved crop health and productivity.
