# 🌿 GPU-Accelerated AI-Based Plant Disease Detection

## Overview

This project detects plant diseases using Deep Learning and NVIDIA GPU acceleration.

The system uses MobileNetV2 Transfer Learning with TensorFlow and provides disease prediction through a Flask web application.

## Features

- Plant Disease Detection
- MobileNetV2 Transfer Learning
- TensorFlow/Keras
- Flask Backend
- HTML/CSS/JavaScript Frontend
- NVIDIA GPU Acceleration
- Google Colab Support
- Kaggle PlantVillage Dataset

## Technologies

- Python
- Flask
- TensorFlow
- Keras
- MobileNetV2
- HTML
- CSS
- JavaScript
- NVIDIA GPU
- CUDA

## Dataset

PlantVillage Dataset (Kaggle)

## How to Run

1. Install Python packages

pip install -r requirements.txt

2. Start Flask

python app.py

3. Open

frontend-index.html

## Results

- Detects plant diseases
- Shows confidence score
- Identifies healthy and diseased plants
